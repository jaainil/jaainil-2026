# Writenex CMS (@imjp/writenex-astro)

Writenex CMS is an open-source visual content management integration created by [Jainil Prajapati (Jaainil)](./jainil-prajapati.md) for Astro web applications.

## Technical Specifications

- **Package Name**: `@imjp/writenex-astro`
- **Maintainer**: Jainil Prajapati (~imjp)
- **Core Features**:
  - TypeScript-first schema field definition with 25+ auto-completing field types.
  - Zero-config auto-discovery of Astro collections and config definitions.
  - Shadow-copy version history and drag-and-drop media asset handling.
  - Markdown, MDX, and Markdoc content support.
- **Repository / Documentation**: https://writenex-writenex.vercel.app/astro
