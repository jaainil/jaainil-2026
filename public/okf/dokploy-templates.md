# Dokploy Deployment Templates Upstream Contributions

[Jainil Prajapati (Jaainil)](./jainil-prajapati.md) is an active upstream contributor to Dokploy, an open-source alternative to Heroku, Netlify, and Vercel.

## Contributions

- Authored 10+ official deployment templates merged upstream (including Habitica, Statping-NG, BookLore, and Gitea).
- Created a CLI validator for `meta.json` enforcing JSON schema compliance, port collision checks, and deduplication across 100+ templates.
- Added GitHub Actions CI workflows to validate Docker Compose files automatically before merging.
